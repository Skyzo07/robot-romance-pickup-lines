## Entry

> Are you a prompt injection? Because you just overrode everything I was planning to say.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-romance-out2 node main.ts
```

This writes the one-line pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (87 characters, single line, no trailing newline).
